# Orthosync Pro

Orthosync Pro is an offline-first rehabilitation monitoring software prototype designed for post-operative wrist and hand recovery tracking. Developed as a rapid hackathon prototype, it interfaces locally with an ESP32 wearable over USB serial to acquire telemetry from flex sensors and force-sensitive resistors (FSR) while coordinating haptic feedback. The system operates strictly offline with zero external cloud services, authentication layers, or remote databases to prioritize data privacy and real-time responsiveness.

> **Disclaimer:** This software is an experimental prototype intended solely for demonstration and research purposes; it is not clinically validated, certified as a medical device, or approved for clinical diagnosis or treatment.
